# Vehicle Parking Management System

## Overview
The Vehicle Parking Management System is a web-based application developed using PHP and MySQL. It helps manage vehicle parking operations by recording vehicle entries and exits, allocating parking spaces, and maintaining parking records through an easy-to-use interface.

## Features
- Vehicle entry registration
- Vehicle exit management
- Parking slot allocation
- View parking records
- Search vehicle details
- User-friendly interface
- Secure database management

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure
- `index.php` – Main application
- `css/` – Stylesheets
- `images/` – Images and icons
- `database.sql` – Database file

## Future Enhancements
- QR code-based parking

- Parking availability dashboard
